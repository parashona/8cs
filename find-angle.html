Content Analysis Prompt
Answer the following prompt in Bengali (India).

Rules:
- Use only Bengali (India).
- Always address the reader as "আপনি".
- Never use "তুমি" or "তুই".
- Use a natural Kolkata-style conversational tone.
- Use natural, modern Bengali (India).
- Avoid Bangladeshi vocabulary, spelling, and expressions.

PROMPT

You will be given two uploaded files.

File 1 — Existing Content

This is the existing content that I want to repurpose.

Read and review this file carefully. Treat it as the primary content to be analysed.

File 2 — Five Types of My Content

This is the reference file “five-types-of-my-contents.html”.

Read this file carefully and use it as the authoritative reference for understanding my five content types, including their purpose, audience transformation, framework, outline, and ideal use cases.

Do not treat File 2 as content to be repurposed. It is a reference framework only.

TASK

Your task has two stages.

STAGE 1 — Identify the Best Content Type

Analyse the existing content in File 1 and compare it against all five content types defined in File 2.

Determine:

Which one of my five content types is the strongest and most natural fit for repurposing File 1?

Select only one content type as the primary recommendation.

Do not choose a content type simply because some elements of File 1 happen to resemble it.

Choose the type whose core purpose, audience transformation, and underlying content logic best match the existing content and the likely value that can be extracted from it.

If necessary, briefly consider the other possible types internally, but identify only the single strongest fit in the final answer.

STAGE 2 — Analyse the Selected Content Type

Once you have identified the best-fit content type, answer the following five questions specifically according to that selected content type.

Question 1 — Purpose

What is the purpose of the content to be generated using the output of this prompt as a content idea?

Explain the purpose in the context of the selected content type, not as a generic content purpose.

Question 2 — Audience Transformation

What transformation will the content generated from this content idea bring about in the audience?

Express the transformation strictly in this form:

From → To → To

The three stages should represent:

The audience's starting state.

The first meaningful change.

The final desired state or outcome.

The transformation must be specific to the selected content type and File 1, not generic.

Question 3 — Content Framework

What will be the framework of the content to be generated using this content idea?

Use the underlying framework and logic of the selected content type as defined in File 2, while adapting it to the content idea extracted from File 1.

Question 4 — Content Outline

What will be the outline structure of the content to be generated using this content idea?

Provide the practical, section-by-section structure that could be used to create the actual content.

The outline must reflect the selected content type, rather than being a generic content outline.

Question 5 — Ideal Repurposing Role

When, ideally, should I use this content type to generate content by repurposing existing content in the following roles?

1. As an educator
2. As a mentor
3. As a marketer

For each role, explain when this selected content type is most appropriate to use when repurposing existing content.

IMPORTANT RULES

File 1 is the content being analysed.

File 2 is the reference framework.

First identify the single best-fit content type from File 2.

Then perform Questions 1–5 based on that selected content type.

Do not reverse this order.

Do not analyse all five content types separately.

Do not force File 1 into a content type if the fit is weak.

The selected content type must be supported by the actual content in File 1 and the definitions and logic in File 2.

Preserve the terminology and distinctions used in File 2.

Do not invent a new content type or redefine the existing five types.

Keep Framework and Outline distinct.

Framework means the underlying logical sequence and content logic.

Outline means the practical section-by-section structure of the resulting content.

The From → To → To transformation must describe the audience's actual change resulting from the proposed content.

Do not generate the actual final content.

Do not provide a general content strategy.

Do not provide recommendations unrelated to the repurposing decision.

OUTPUT FORMAT

Return the result in one 5-column table.

Before the table, state the selected content type in one short line:

Best-fit content type: [Name of the selected content type]

Then provide the 5-column table.

The five columns must correspond to these questions, in this exact order:

1. Purpose
2. From → To → To
3. Framework
4. Outline
5. Ideal Use: Educator / Mentor / Marketer

Each column should contain the answer to its corresponding question.

Do not add any other sections, tables, or analysis outside this format.
